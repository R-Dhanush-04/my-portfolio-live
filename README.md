# Dhanush R - Ultra Pro Violetic Portfolio

Enterprise Java Full Stack Developer Portfolio crafted with **Core Java 21 & Spring Boot showcase**, **React.js**, **Tailwind CSS**, and **Bootstrap 5 & Icons**.

---

## 🚀 Running in Visual Studio Code (Two Options)

### Option 1: Modern Vite Dev Server (Default / Full Stack)
1. Open this project directory in **Visual Studio Code**.
2. Open the integrated terminal (`Ctrl + ~` or `Cmd + ~`).
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the dev server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
6. Alternatively, press **F5** in VS Code to launch using the pre-configured `.vscode/launch.json`.

---

### Option 2: Standalone HTML, CSS, JavaScript & Bootstrap (Zero-Build)
For a direct, zero-configuration setup using pure HTML5, CSS3, vanilla JavaScript, and Bootstrap 5:
1. In VS Code, navigate to the `standalone/` directory.
2. Right-click on `standalone/index.html` and select **"Open with Live Server"** (using the popular VS Code Live Server extension by Ritwick Dey).
3. Or double-click `standalone/index.html` in your file explorer to open directly in any browser!

## 🌟 Key Features

1. **Ultra Pro Violetic Theme**:
   - Deep obsidian canvas (`#06050c`), royal violet glass cards (`#0e0922`), glowing neon nebula orbs, and iridescent borders.
   - Interactive HTML5 constellation particle canvas responding to cursor physics.

2. **3D Interactive Profile Flip Card**:
   - **Front Face**: Dhanush R's developer portrait framed with glowing violet borders and verified Java 21 status.
   - **Back Face**: Interactive **Welcome Boy** avatar (`welcome-boy.png`) with celestial halo, animated speech bubble, and speech greeting trigger.

3. **External Resume Section & AI Bot Upper Dock**:
   - **Above AI Bot**: An **External Resume Dock** is positioned directly upper/above the floating AI assistant button. Clicking the "Resume" pill reveals a glassmorphic quick-access panel with direct links to `/Dhanush_R_Resume 1.pdf`.
   - **Dedicated Section**: The `#resume` section in the portfolio presents verified credentials (B.E. CSE 8.1 CGPA, Login360 Java Full Stack), an ATS match scorecard (95% Fit), direct PDF download, and custom URL persistent configuration.

4. **Speech Synthesis & Web Audio FX**:
   - Spoken guided audio tours covering Dhanush's introduction, technical skills, projects, and recruiter fast-track.
   - Web Audio synthesizer providing futuristic UI audio chimes with an on/off toggle.

5. **Recruiter Fast-Track & AI Assistant**:
   - One-click HR candidate dossier with contact details and WhatsApp chat.
   - Interactive AI Assistant drawer ready to answer questions about Dhanush's background, skills, and projects.
